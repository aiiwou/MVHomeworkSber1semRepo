# AquaManager

REST API для управления каталогом аквариумных рыб: просмотра, добавления, изменения и удаления записей. Подойдёт работником океанариумов, или магазинов рыб

## Как разрабатывали

Для разработки использовался AI-агент **OpenAI Codex** на базе модели **GPT-5.6-Codex**.

**Основной промт:**

> Разработай REST API для управления каталогом аквариумных рыб. Предусмотри 4–5 endpoints с использованием разных HTTP-методов: получение списка рыб, получение одной записи, создание, обновление и удаление. Добавь параметры запросов, DTO-схемы, авторизацию и обработку ошибок. Подготовь спецификацию OpenAPI 3.0.

**Дополнительные промты:**
- Помоги определить структуру DTO и разделить входные и выходные данные.
- Проверь корректность HTTP-статусов и ответов при ошибках.
- Помоги подготовить спецификацию для генерации приложения через OpenAPI Generator.

## Что исправлял вручную

- Проверил и исправил структуру YAML в Swagger Editor. А именно описания HTTP-ответов и примеры ошибок, т.к. до этого у разных ошибок были одинаковые описания.
- Проверял работу сгенерированного приложения и отображение методов в Swagger UI.
